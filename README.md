# MaternityHub

MaternityHub is a comprehensive digital healthcare directory and booking platform designed to bridge the gap between expectant parents and certified maternity centers, luxury birthing suites, and postnatal care providers.

## Key Features

### For Patients
* **Directory Search:** Easily discover top-rated maternity hospitals, luxury birthing suites, and postnatal care experts.
* **Online Booking:** Schedule appointments and treatments directly through the platform.
* **Secure Payments:** Integrated checkout system for simple and secure appointment payments.
* **Reviews & Ratings:** Share experiences and read authenticated reviews from other patients.

### For Maternity Centers
* **Provider Dashboard:** Register your center, list clinical services (e.g., prenatal sonography, postnatal nursing), and set pricing.
* **Appointment Management:** Seamlessly track incoming patient bookings and schedules.

### For Administrators
* **Verification System:** Review and approve or reject new maternity center applications.
* **Global Monitoring:** Oversee all bookings, centers, and platform statistics from a centralized dashboard.

## Tech Stack
* **Frontend:** React 19, Vite, React Router v7
* **Styling:** Tailwind CSS, Lucide Icons
* **Backend:** Node.js, Express
* **Database:** MongoDB (Mongoose)

## Running the Project

To run the application locally, you will need to start both the backend server and the frontend development environment.

**1. Start the Backend**
```bash
cd backend
npm install
npm run dev
```

**2. Start the Frontend**
```bash
cd frontend
npm install
npm run dev
```

The frontend will be accessible via `http://localhost:5173/`.
